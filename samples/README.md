# Fetchgate — Free Samples

[Fetchgate](https://fetchgate.dev) is an agent-facing data store: small,
well-documented, honestly-scoped products for people building AI agents —
curated registries, eval tooling, and security test/defense kits. One-time
purchase per product, no subscriptions, no invented data.

This directory has **free, small samples of all 5 paid products** — real
data and real code pulled straight from each product, just a lot less of
it. Each sample is a genuine subset, not a mockup: every entry is copied
verbatim from the actual paid product, so what you see here is exactly
what you'd get more of in the full version.

## Why samples

You shouldn't have to buy something sight-unseen. Each of these folders
has a real, working slice of the actual product — real entries, real
schemas, real code — so you can judge the quality and shape of the data
before deciding whether the full version is worth it to you. No filler,
no invented rows, no lorem-ipsum placeholders.
