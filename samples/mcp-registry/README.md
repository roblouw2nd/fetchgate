# MCP Server Registry Snapshot — Free Sample

This is a **free sample** of Fetchgate's *MCP Server Registry Snapshot*: a
curated, machine-readable directory of Model Context Protocol (MCP)
servers — what each one does, how it's reached (transport, auth), where
its source lives, and which public directory it was found in.

**Free sample: 30 of 400 MCP servers**, spread across all 14 categories in
the full registry (dev-tools, data-db, productivity, devops-cloud,
communication, media, ai-ml, search-web, finance, browser-automation,
security, file-storage, knowledge-memory, other).

- [**Get the full registry ($19)**](https://growthchief5.gumroad.com/l/mcp-registry)

## What's in this sample

- `data/servers-sample.json` — 30 of the 400 servers in the full edition:
  name, category, transport, description, auth requirement, repo/package
  URL, source directory, source URL(s), verification date, maintainer,
  and honesty notes, exactly as they appear in the full dataset.

Every entry is copied **verbatim** from the paid product — nothing here is
invented or reworded.

## Why it's small

This is a teaser, not the product. The full registry has 400 servers
across every category above, plus a JSON Schema for validating/ingesting
the data programmatically and a sortable Markdown table for humans. See
the [full product listing](https://growthchief5.gumroad.com/l/mcp-registry)
for coverage notes and what's included.
